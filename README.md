
# psp-paf

psp-paf is mostly a header library that provides the declaration of classes and  dynamically links to Sony's `scePaf_module` for Playstation Portable. There are also few headers that recreate stuff that is not getting exported, because there is no clean way to link against it (also it's nice to have source), it's mostly theirs (Sony) std recreation.

## Building
This will build the static lib and build the samples found in `/samples`
```
psp-cmake -B build -DBUILD_SAMPLES=ON
cmake --build build
```

## Usage
- Build/link against it eg. with CMake
```cmake
add_subdirectory(path/to/psp-paf)
target_link_libraries(name PRIVATE
    psp-paf
)
```
